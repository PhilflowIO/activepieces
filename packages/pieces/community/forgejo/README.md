# pieces-forgejo

Forgejo piece: find, list and create issues, create an epic with sub-issues, comment on an issue and add labels. Works with any Forgejo or Gitea instance through a personal access token; the repository is a parameter of every action.

Parts of `src/lib/common/client.ts` are adapted from `packages/pieces/community/gitea` (MIT Expat, Copyright (c) 2020-2024 Activepieces Inc.).
